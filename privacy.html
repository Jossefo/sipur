מה נמצא בקישור?

שם או כינוי, גיל ותוכן הספר מקודדים אחרי סימן # בקישור לסיפור. חלק זה אינו נשלח לשרת GitHub Pages. הקידוד אינו הצפנה. כל מי שמקבל את הקישור יכול לפתוח ולפענח אותו, ולכן כדאי להשתמש בשם פרטי או בכינוי ולהימנע ממידע רגיש.

איפה נשמרים הספרים?

הספרייה נשמרת בדפדפן במכשיר הזה, ללא חשבון משתמש. מחיקת נתוני הדפדפן תמחק אותה. קישור שהעתקתם ימשיך להכיל את תוכן הסיפור; אין אפשרות לבטל גישה לקישור שכבר שותף.

האיורים והמשוב

האיורים מוגשים מתוך הפרויקט. פרטי הסיפור אינם נשלחים לשירות יצירת תמונות חיצוני. משוב שומר רק דירוג ומזהה תבנית בדפדפן שלכם. הוא אינו נשלח לשרת או לבעל הפרויקט. אין איסוף שמות, קישורים לסיפורים או הערות חופשיות.

שירותים נוספים

האתר טוען גופנים מ־Google Fonts ומנוע הרצת Python מדפדפן CDN של jsDelivr. יצירת הסיפור מתבצעת במכשיר, ללא שליחת שם, גיל או רגעים לשירות חיצוני. ספקי האחסון עשויים לתעד כתובות IP ובקשות לקבצים. הסיפורים בקישורים משותפים נמצאים אחרי סימן # ואינם נכללים בבקשת השרת. אין העברת כתובת הסיפור כ־referrer. אלה אינם תחליף לבקרת גישה.

פרויקט פתוח, בלי הבטחות מיותרות

סיפור הוא פרויקט עצמאי ליצירת סיפורים בעברית באמצעות קוד ותבניות. אין צורך במפתח API, אין הרשמה ואין מנוי בתשלום.
